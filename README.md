# Annase's quote form

A single web page with the quote form code, Wix setup steps, a live preview and the picture pack.

- `index.html` is the whole page
- `pictures/` holds the images (PNG and SVG)
- `annase-pictures.zip` is the one-click download of all the pictures

## Put it on GitHub

1. On github.com, create a new repository (private is fine). Name it something like `annase-quote-form`.
2. Open the repository, choose Add file, then Upload files.
3. Drag in everything from this folder: `index.html`, `README.md`, `annase-pictures.zip` and the `pictures` folder.
4. Commit the changes.

## Put it live on Netlify

1. Log in to Netlify and choose Add new site, then Import an existing project.
2. Connect GitHub and pick the repository.
3. Leave the build command empty and leave the publish directory empty (or a single dot). Deploy.
4. Change the site name under the site settings so the link is easy to share.

Quicker option without GitHub: drag this whole folder onto Netlify Drop (app.netlify.com/drop).

Menu names on both sites change now and then, so look for the closest match.
