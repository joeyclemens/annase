2_add_to_wix.exe_□×
  1. Open your site in the Wix Editor and go to the page where the form should live.
  2. Add an HTML box. Click Add Elements (the plus on the left), choose Embed Code, then Embed HTML. In Wix Studio it is Add Elements, Embed & Social, HTML Embed.
  3. Paste the code. Click the new box, choose Enter Code, pick the Code option, paste what you copied in step 1 and press Update.
  4. Give it room. Stretch the box to the full width of the page and about 1000 px tall. The form changes height as people move through it, so if you see a scrollbar inside the box, make it taller.
  5. Preview, then publish. Click through the form in Preview and publish when you are happy.
  6. Send one test request. Fill the form in on your live page and submit it. The first time, the form service emails you a confirmation link. Click it, and every request after that arrives normally. Check spam if it does not show up.

Change the prices OPTIONAL

Near the top of the code's script section there is a list called PRICES. Each project type has a price per square metre for london and for outside. Change the numbers, copy the code again and paste it over the old version in the Wix box.

help.txt_□×
The form is cut off or has its own scrollbar

Make the Wix box taller. Select it in the editor and drag the bottom edge down, or set the height in the box's size settings.

No emails are arriving

The first request triggers a confirmation email from the form service. Open it and click the link. Look in spam too. After that, send another test.

Some visitors see "Estimate not available"

That is intended. The estimate only appears when someone enters the size of their project. Everyone else is told you will arrange a site survey.

I want to change the purple

The main colour is #7c3aed, and its darker shade is #6d28d9. Replace those in the code with your own colours and paste it into Wix again.
